# データの取り扱い方針

このリポジトリが含むのはコードです。試合映像も、切り出した静止画も、ラベルファイルも、モデルの重みも含みません。これらがコミットされた場合はCIが落ちます。

この映像に写っているのはアマチュアの学生選手です。クラブや連盟が試合を記録することを選んだという事実は、第三者がそこに写る個人の映像を再配布してよいという同意ではありません。そして映像は、この作者が [togakuren-analytics](https://github.com/sean-from-japan/togakuren-analytics) ですでに方針を定めた出場記録よりも、はるかに個人が特定されやすい記録です。

これを動かす人に対する帰結は次のとおりです。

- 映像は `data/` の下に置いてください。ここはgitの対象外です。撮影したチームが合意した保管場所から動かさないでください。
- ラベルファイルが記述するのは事象であって人ではありません。選手を識別する列はありませんし、背番号の認識は明確に対象外です。
- 実行結果から公開するもの（図・結果の表・READMEの数値）は、すべて集計値です。件数・再現率・確認時間であって、クリップでも静止画でも特定個人の軌跡でもありません。
- 他人が撮影した映像を使う前に、その用途を特定したうえで書面で合意を取ってください。公開する報告の中に1フレームでも映像を出してよいかどうかも含めてください。

## このデータセットは、カードに書かれているほど仮名化されていません

SoccerTrack v2 のカードには、このリリースは仮名化済みで、個人名は背番号に置き換えてあると書かれています。これは `gsr/`・`bas/`・`mot/` については成立しています。

`raw/` については成立していません。各 `<match>_player_nodes.csv` には、**選手の実際の姓名**と背番号、所属クラブ名が、イベントフィードと並んで入っています。試合118577のファイルには、そうした行が2,384件あります。

このリポジトリにとっての帰結は、上に書いたすべてに加えて次のとおりです。

- `raw/` はデータであり、データはコミットしません。ここは何も変わりません。
- `raw/` を読むコードは、必要なフィールド**だけ**を読みます。`corner_labels()` が取るのは時刻・前後半・チームIDで、名前がプログラムに入ってくることはありません。
- `raw/` から派生したものは、名前を含む形では一切公開しません。例示・図・コミットメッセージも含みます。
- メンテナに知らせるべきです。仮名化を約束するカードと、名前を持つファイルとの食い違いは、このデータを使う側だけでなく、そこに写っている学生にとっての問題です。
