# 映像の入手先

このプロジェクトが必要とするのは、**固定広角カメラ**で撮った試合全体です。検証しようとしている主張が、そのカメラについてのものだからです。中継映像はカットが入り、ズームし、リプレイを挟みます。そして中継におけるコーナーキックは、ディレクターのカメラ切り替えによって予告されます。これはタッチライン脇のカメラには存在しない信号なので、中継映像で評価すればどんな検出器も実力以上に見えます。

2026-09-05 に確認しました。

## 第一候補 — SoccerTrack v2

| | |
|---|---|
| 内容 | 大学レベルの10試合、934分、4Kパノラマ、合計145 GB |
| カメラ | BePro の固定多眼パノラマ合成（8試合）と BePro Cerberus（2試合） |
| ライセンス | CC BY 4.0、仮名化済み（氏名は背番号に置換） |
| 入手 | Hugging Face `atomscott/soccertrack-v2`、承認制（アカウントと利用条件への同意が必要） |
| 論文 | [arXiv:2508.01802](https://arxiv.org/abs/2508.01802) |
| 同梱物 | 状態注釈、ボールアクション事象、フレーム単位のボール軌跡、試合ごとのピッチ較正 |

データセットカードによる内訳です。

| フォルダ | 中身 |
|---|---|
| `videos/` | パノラマのハーフ映像20本（1試合あたり45分の前後半2本） |
| `gsr/` | ハーフ単位のフレームごとの状態。ピッチ座標、背番号由来の識別、役割、チームの側 |
| `bas/` | ボールアクション事象、12クラス、実行チームと実行選手つき |
| `ball/` | ハーフ単位のフレームごとのボール軌跡 |
| `mot/` | MMSports 2025 チャレンジ用の部分集合。検出枠つきの4分クリップ |
| `raw/` | 試合ごとのピッチ特徴点、歪み補正マップ、カメラ内部パラメータ |

分割は固定されています。テストが128057と132831、検証が117093と132877、残る6試合が学習用です。ピッチ座標は105 x 68 mのメートル系で、原点はセンターサークルです。

対象領域に最も近い公開データはこれです。大学サッカー、固定パノラマカメラ、クリップではなくハーフ単位、そして出典表示で利用できるライセンスが揃っています。この作者の `togakuren-analytics`（日本の大学リーグの記録を扱っています）と同じ母集団から来ている点も同じです。

**コーナーは、注釈されている12種の事象クラスに含まれていません。** クラスの一覧は Pass、Drive、Header、High Pass、Out、Cross、Throw In、Shot、Ball Player Block、Player Successful Tackle、Free Kick、Goal です。したがってコーナーの教師データは人手で作る必要がありますが、これはもともとこのプロジェクトがやる予定だった作業です。そして既存のラベルは独立した照合手段になります。コーナー付近からの `Out` に続く `Cross` はコーナーですから、その再構成と人手のラベルとの食い違いは、ラベル付けそのものに対する測定になります。

## ダウンロードの進め方

145 GBを一度に落とす必要はありませんし、その必要も生じません。順序は次のとおりです。

1. **注釈だけ** — `gsr/`・`bas/`・`ball/`・`raw/` です。容量が小さく、付属の追跡データに対してコーナー検出器を作って測るにはこれで足ります（D8）。
2. **ハーフ単位で1本ずつ** — これまでに測ったハーフで3.3 GBです。間引いて走査し、検出結果をキャッシュしたら映像は消します。以降の作業が読むのはキャッシュで、映像ファイル自体は一度だけ必要になります。`HF_HUB_DISABLE_XET=1` を付け、ダウンロード後にファイルサイズを確認してください（[DATASET_NOTES.ja.md](DATASET_NOTES.ja.md)）。
3. **測定が必要とするときだけ、さらにハーフを追加** — テスト用の2試合は、検出器が変わらなくなるまで手を付けません。

## 次善策 — Alfheim（Simula）

トロムソILの2013年の試合3本を丸ごと収録したもので、ハーフウェーライン付近の固定カメラ群から合成したパノラマに加え、身体装着センサによる20 Hzの選手座標が付いています。引用すれば研究用途で自由に使え、承認手続きもありません（<https://datasets.simula.no/alfheim/>）。

アマチュアではなくプロで、しかも11年古いので、SoccerTrack v2 のアクセスが下りなかった場合の代替です。下りた場合にも対照として使えます。同じ検出器をプロと大学の映像に当てた比較は、まだ誰も公開していません。

## 適さないもの

- **SoccerNet / SN-spotting / FOOTPASS** — 欧州リーグの中継映像です。公開されているアクションスポッティングの数値と比べるには優れていますが、このプロジェクトが立てている問いには合いません。
- **当初の構想で挙げていた62秒のクリエイティブ・コモンズ映像** — 処理系が動くことを示すには足りますが、再現率の数値を出すには足りません。クリップが1本では、見落とすコーナーがありません。

## 自分で撮る映像

いずれは持っておく価値があります。日本の大学の試合を三脚に載せたカメラで撮る状況は、まさにこのプロジェクトが主張している運用そのものです。そうした試合が1本あれば、BeProのパノラマで得た結果が、三脚に載せたスマートフォンでも成立するかどうかが分かります。他人を撮影するには事前の合意が必要です（[DATA_POLICY.ja.md](DATA_POLICY.ja.md)）。
