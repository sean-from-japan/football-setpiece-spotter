# 試合にラベルを付ける

教師データは検出器より先に作ります。検出器を先に作ると、それを有利に見せる方向へ静かに形の変わったラベルで採点することになるからです。

## 形式

1試合につき1つのCSVを、映像と同じ `data/` の下に置きます。コミットはしません。

```csv
time,event,team,note
00:12:31,corner,home,ショートコーナー
00:24:42,corner,away,
00:38:51,corner,home,クリアがそのままタッチを割った
```

`setpiece template` を実行すると、使える語彙の入った空のファイルが出ます。

- **time** — 再開が*実際に行われた*時刻です。ボールが外に出た時刻でも、主審が笛を吹いた時刻でもありません。`12:31`・`00:12:31`・`751` はすべて同じ瞬間を指します。
- **event** — `corner`・`throw_in`・`free_kick`・`goal_kick`・`kick_off`・`penalty`・`goal` のいずれかです。
- **team** — 任意です。広角の大きさで、ピッチのどの位置でも両チームを見分けられる試合にラベルを付けるときだけ埋めてください。
- **note** — 自由記述です。この時刻の近くの候補が後で議論になったときに意味を持つことを書いてください。

## 手順

1. 早送りではなく等倍で、ストップウォッチを表示しながらラベルを付けてください。早送りで見つかるのは、自分が覚えているコーナーだけです。
2. 静かだろうと予想しているハーフも含めて、試合を最後までラベル付けしてください。再現率は試合全体に対してでなければ意味を持ちません。
3. 各ハーフのキックオフの時刻を記録してください。ハーフタイムでの陣地の入れ替わりが、攻撃方向の推定を反証可能にします。
4. 1試合を、日を変えて**2回**ラベル付けしてください。そして2回目を1回目に対して `setpiece evaluate` で採点してください。その数値が上限です。検出器は、ラベル付けの一貫性を超えて優れていることを示せません。そして人間による2回のラベル付けの食い違いが、他のすべての場面で使う許容幅を決めます。

## なぜ許容幅を広く取るのか

このツールの出力は、人間が開くクリップです。現在の長さは30秒です。10秒早い候補でも、確認する人には正しい再開の場面が見えます。それを見落としとして採点すると、確認する人が一度も経験しない何かを測ることになります。既定は±15秒で、この値はすべての数値の隣に書くべきです。±15秒での再現率と±2秒での再現率は、別の主張だからです。
